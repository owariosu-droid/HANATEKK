# HANATEKK JEDM

Independent electronic music label website. HTML, CSS, and JavaScript with no runtime dependencies or build step.

## Develop

Requires Node.js 20 or newer. Run `npm run dev` to serve on port 3000 (`PORT` overrides it). Run `npm run check` for JavaScript syntax checks.

Deploy `index.html`, `style.css`, `app.js`, and `assets/` to any static host. `server.mjs` is for local development.

## Music and artwork

The release link points to the supplied Bandcamp album. The cover is original website placeholder artwork, not the original album cover. No tracklist or release date has been invented.

**Load your tracks** selects audio files from your device. The player supports playlists, play/pause, previous/next, seeking, volume, and automatic advance. Files remain local and disappear on reload. This does not publish songs for visitors. Public streaming requires adding authorized audio files and a permanent track manifest. No songs are bundled.

Google Fonts enhances typography when available; system fonts work offline. No analytics, account system, or checkout is configured.
